# Журнал проекта

Журнал помогает восстановить контекст после перерыва. Новые записи добавляются
сверху, чтобы последнее состояние было видно сразу.

## 2026-09-02 — автоматические проверки в GitHub Actions

### Сделано

- создана отдельная ветка `chore/add-ci`;
- добавлен CI для push и Pull Request в `main`;
- CI устанавливает Python и зависимости из lock-файла;
- CI запускает Ruff, mypy и pytest в Linux;
- в README добавлен индикатор состояния CI;
- описан процесс работы через ветки и Pull Request.
