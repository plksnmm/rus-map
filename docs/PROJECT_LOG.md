# Журнал проекта

Журнал помогает восстановить контекст после перерыва. Новые записи добавляются
сверху, чтобы последнее состояние было видно сразу.

## 2026-09-02 — локальная база PostgreSQL/PostGIS

### Сделано

- создана Issue №5 и ветка `chore/add-postgis`;
- установлен Docker Desktop с WSL 2 backend;
- хранилище Docker перенесено на диск `D:`;
- добавлен Compose-сервис PostgreSQL 18 с PostGIS 3.6;
- настроены named volume и healthcheck;
- порт базы опубликован только на localhost;
- из-за системной резервации `5432` выбран host-порт `15432`;
- SQL-запросом подтверждена работа PostGIS 3.6;
- в CI добавлена валидация Compose-конфигурации.

### Изучено

- различие Docker image, container и volume;
- различие host-порта `15432` и container-порта `5432`;
- назначение healthcheck;
- разделение публичного `.env.example` и локального `.env`;
- проверка расширения PostGIS через `psql`.
