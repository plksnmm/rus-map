# HTTP API

## Общие соглашения

- Версионированный API использует префикс `/api/v1`.
- Запросы и ответы используют JSON.
- Координаты передаются десятичными числами в системе WGS 84.
- Интерактивный контракт OpenAPI доступен локально по адресу `/docs`.

Системный endpoint `/health` не версионируется, потому что используется для
проверки экземпляра приложения, а не представляет продуктовую бизнес-функцию.

## Получение списка мест

### Запрос

```http
GET /api/v1/places
```

Параметры запроса пока не поддерживаются.

### Успешный ответ

Статус: `200 OK`.

```json
{
  "items": [],
  "total": 0
}
```

`items` содержит краткие представления мест. `total` содержит общее количество
мест, соответствующих запросу, и не может быть отрицательным.

Поля одного места:

| Поле | Тип | Ограничения |
| --- | --- | --- |
| `id` | UUID | обязательное уникальное значение |
| `title` | string | от 1 до 200 символов |
| `latitude` | number | от −90 до 90 включительно |
| `longitude` | number | от −180 до 180 включительно |

Сейчас endpoint всегда возвращает пустую коллекцию. Хранение и чтение реальных
мест будет реализовано отдельно без изменения базовой формы ответа.
