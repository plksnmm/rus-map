# HTTP API

## Общие соглашения

- Версионированный API использует префикс `/api/v1`.
- Запросы и ответы используют JSON.
- Координаты передаются десятичными числами в системе WGS 84.
- Интерактивный контракт OpenAPI доступен локально по адресу `/docs`.

Системный endpoint `/health` не версионируется, потому что используется для
проверки экземпляра приложения, а не представляет продуктовую бизнес-функцию.

## Создание места

### Запрос

```http
POST /api/v1/places
Content-Type: application/json
```

```json
{
  "title": "Завод Красный богатырь",
  "description": "Историческое здание",
  "latitude": 55.8031,
  "longitude": 37.6917
}
```

Название обязательно, очищается от пробелов по краям и содержит не более 200
символов. Необязательное описание содержит не более 10 000 символов.

### Успешный ответ

Статус: `201 Created`. Ответ содержит переданные поля, сгенерированный UUID и
временные метки `created_at` и `updated_at`.

PostGIS принимает точку в порядке `POINT(longitude latitude)`. Некорректное
название, описание или координаты возвращают `422 Unprocessable Entity` без
вызова repository.

## Получение списка мест

### Запрос

```http
GET /api/v1/places
```

Параметры запроса пока не поддерживаются.

### Успешный ответ

Статус: `200 OK`.

```json
{
  "items": [],
  "total": 0
}
```

`items` содержит краткие представления мест. `total` содержит общее количество
мест, соответствующих запросу, и не может быть отрицательным.

Поля одного места:

| Поле | Тип | Ограничения |
| --- | --- | --- |
| `id` | UUID | обязательное уникальное значение |
| `title` | string | от 1 до 200 символов |
| `latitude` | number | от −90 до 90 включительно |
| `longitude` | number | от −180 до 180 включительно |

Endpoint читает места из PostgreSQL через асинхронный repository. Широта
извлекается из PostGIS Point функцией `ST_Y`, долгота — функцией `ST_X`.
Результаты упорядочены по времени создания и UUID. Пустая таблица возвращает
показанную выше пустую коллекцию без изменения формы ответа.
