# ADR 0008: хранить изображения мест в собственном хранилище

- Статус: принято
- Дата: 2026-09-05

## Контекст

URL фотографий из Telegram CDN могут истечь, внешние сайты могут запретить
hotlink, а большая фотография замедляет карточку. При этом источник и старая
версия материала должны сохраняться.

## Решение

Исходник и оптимизированный WebP хранятся в постоянном Docker-томе. Таблица
`app.media_assets` содержит хэши, пути, MIME-типы, размеры и геометрию.
`MaterialRevision.media_asset_id` связывает файл с неизменяемой ревизией, а
`url` сохраняет ссылку на первоисточник.

Публичный endpoint проверяет опубликованный материал и опубликованную ревизию.
Закрытый импортёр проверяет SHA-256, тип и размер файла и поддерживает dry-run.

## Последствия

- фотографии не зависят от времени жизни внешнего CDN;
- старые ревизии не перезаписываются;
- резервная копия PostgreSQL теперь недостаточна: отдельно архивируется
  `media_data`;
- локальный Docker-том подходит для одного сервера, а при горизонтальном
  масштабировании интерфейс хранения нужно заменить на S3-совместимый backend.
