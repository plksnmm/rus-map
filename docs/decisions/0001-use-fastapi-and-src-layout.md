# ADR 0001: FastAPI и src-структура проекта

- Статус: принято
- Дата: 2026-09-02

## Контекст

Проекту нужен типизированный Python API, автоматически создаваемая OpenAPI-схема
и удобное тестирование HTTP-сценариев. Код пакета также нужно отделить от файлов
репозитория, чтобы тесты проверяли установленный пакет, а не случайный импорт из
текущей папки.

## Решение

Использовать FastAPI для HTTP API и хранить пакет `rus_map` внутри каталога
`src`. Создавать приложение через функцию `create_app()`.

## Последствия

Положительные:

- типы и модели запросов интегрированы с OpenAPI;
- API можно проверять через TestClient;
- структура подходит для роста и разделения на модули;
- фабрика упрощает будущую тестовую конфигурацию.

Ограничения:

- разработчику нужно устанавливать пакет в виртуальное окружение;
- по мере роста потребуется явно разделить HTTP-, бизнес- и инфраструктурный
  слои.
