# ADR 0004: React, Bootstrap и MapLibre для веб-клиента

- Статус: принято
- Дата: 2026-09-02

## Контекст

Проекту нужен адаптивный интерфейс с интерактивной картой, похожей по основным
возможностям перемещения и масштабирования на массовые картографические сервисы.
Интерфейс должен быть удобен для постепенного развития и автоматического
тестирования, а картографическая библиотека не должна привязывать проект к
закрытому SDK.

## Решение

Использовать React с TypeScript и Vite как основу отдельного frontend-приложения.
Bootstrap отвечает за компоновку и стандартные элементы интерфейса, а MapLibre
GL JS — за WebGL-карту, навигацию, слои и будущие маркеры. Компонентные тесты
выполняются Vitest и React Testing Library в jsdom.

Bootstrap не является картографическим движком и не заменяет MapLibre. Эти
библиотеки решают разные задачи и используются совместно.

## Последствия

- frontend имеет отдельные npm-зависимости и lock-файл;
- CI отдельно проверяет backend и frontend;
- WebGL-карту можно развивать независимо от панелей Bootstrap;
- MapLibre worker требует явной настройки при сборке через Vite;
- картографический стиль и тайловый сервис остаются заменяемыми;
- MapLibre увеличивает размер клиентского JavaScript, поэтому компонент карты
  загружается отдельным chunk с бюджетом 1000 kB; дальнейшую оптимизацию нужно
  контролировать по мере роста клиента.
