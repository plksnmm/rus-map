# ADR 0007: Версионируемые материалы места

- Статус: принято
- Дата: 2026-09-04

## Контекст

Одна точка карты со временем получает новые тексты, фотографии, видео, новости
и исправления. Перезапись одного поля `description` уничтожила бы историю и не
позволила бы независимо модерировать разные источники. Новая редакция также не
должна скрывать уже опубликованную информацию до завершения проверки.

## Решение

Место остаётся устойчивой сущностью с постоянным UUID. Связанные сведения
хранятся в `app.materials`, а их содержимое — в неизменяемых пронумерованных
записях `app.material_revisions`.

И материал, и каждая редакция имеют статусы `pending_review`, `published`,
`rejected`, `archived`. Публичный endpoint выбирает только опубликованные
материалы и последнюю опубликованную редакцию каждого из них. Более новая
редакция на проверке не видна публично и не скрывает предыдущую одобренную.

Редакция содержит ровно одно полезное значение: текст либо HTTP(S)-URL. Тип
материала показывает назначение значения: текст, внешняя ссылка, изображение,
видео или аудио. Обычная модерация меняет статус, а не удаляет строки.

## Последствия

Преимущества:

- сохраняется полная история исправлений;
- новые материалы дополняют точку без дублирования места;
- премодерация не раскрывает непроверенные сведения;
- опубликованная версия остаётся доступной во время проверки новой редакции;
- типы материалов можно одинаково использовать в web- и будущем Android-клиенте.

Ограничения:

- запрос сложнее простой загрузки одного поля и использует оконную функцию;
- текущая задача добавляет только публичное чтение, без административной записи;
- физические файлы и объектное хранилище появятся отдельно;
- авторство пока хранится свободным полем `source`; пользователи и журнал
  действий потребуют отдельных сущностей.

## Альтернативы

### Перезаписывать описание места

Отклонено: теряются старые сведения, источники и возможность аудита.

### Хранить только материалы без редакций

Отклонено: исправление снова потребовало бы перезаписи или создания ложного
дубликата материала.

### Один статус только у материала

Отклонено: новая непроверенная редакция либо становилась бы публичной, либо
временно скрывала бы предыдущую опубликованную версию.
