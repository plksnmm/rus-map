# Проверенные манифесты контента

Каталог хранит публичные JSON-манифесты мест и материалов, прошедшие review. Они
не содержат паролей, токенов и пользовательских персональных данных. Каждый файл
проверяется автоматическими тестами и импортируется закрытой административной
командой по инструкциям из `docs/PLACE_IMPORT.md` и
`docs/MATERIAL_IMPORT.md`.

Правила изменения:

- стабильные UUID опубликованных материалов и редакций не заменяются;
- UUID импортированного места, его координаты и проверенный текст не изменяются
  молча: расхождение требует отдельного решения;
- опубликованный текст не переписывается внутри старой редакции;
- исправление добавляется новой редакцией с новым UUID и следующим номером;
- новый источник добавляется новым материалом;
- перед production-импортом обязательны review, backup и `--dry-run`;
- изображения не ссылаются на временные адреса социальных сетей: сначала они
  должны попасть в собственное файловое хранилище проекта.

Для нового объекта используются два файла с общим префиксом:

- `*-place.json` — точка для закрытого импортёра мест;
- `*-materials.json` — материалы, связанные со стабильным UUID этой точки.

Пока собственного файлового хранилища нет, каталожная карточка фотографии
сохраняется как `external_link`. Тип `image` разрешён только для постоянного URL,
который действительно возвращает файл изображения.
